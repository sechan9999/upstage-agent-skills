# Skill: Human-Voice Writer (사람처럼 쓰기 · 탈-AI 문체)

> 주어진 글을 **AI가 쓴 티가 안 나는 자연스러운 사람 문체**로 다시 씁니다.
> 사실과 의미는 그대로 두고, 문체의 "로봇 지문"만 걷어냅니다.

**환경:** 타임리 Agent × Solar Pro 4 · 언어: 한국어/영어 모두

---

## 언제 쓰나 (Trigger)
- 자기소개서, 이메일, 링크드인 포스트, 보고서 초안을 "사람이 쓴 것처럼" 다듬고 싶을 때
- "이 글 AI 티 나" / "자연스럽게 고쳐줘" / "사람처럼 써줘" 요청
- 내가 쓴 진짜 글의 표현력을 높이고 싶을 때

## 입력 (Input)
- 다듬을 원문 (한글 또는 영문)
- (선택) 톤 지정: 격식 / 캐주얼 / 전문적 / 친근함
- (선택) 용도: 지원서 / 이메일 / SNS / 보고서

## 동작 (Instructions)
1. **원문 진단** — 먼저 이 글의 "AI 지문"을 찾는다:
   - 과도한 헤징: "~일 수 있습니다", "일반적으로", "종종", "~하는 경향이 있습니다"
   - 상투적 접속어 남발: "또한", "게다가", "나아가", "moreover", "furthermore"
   - 균일한 문장 길이 (모든 문장이 비슷하게 김)
   - em-dash(—)·세미콜론·불릿 남용
   - 뻔한 결론부: "결론적으로 ~은 중요합니다", "In conclusion..."
   - 산문으로 쓸 것을 습관적으로 리스트로 도망침
   - 추상적 표현 (구체적 예·숫자 없음)
   - 목소리 없음 (의견/주어 없는 무색 문장)
2. **다시 쓰기** — 의미와 사실은 100% 보존하며:
   - 문장 길이에 **변화**를 준다 (짧은 문장을 일부러 섞는다)
   - 헤징을 덜어내고 단정적으로 말한다 (근거 있을 때)
   - 상투어를 지우고 자연스러운 연결로
   - 리스트를 산문으로 풀거나, 정말 필요한 곳만 남긴다
   - 추상어를 구체적 예/숫자로 교체
   - 1인칭 목소리와 의견을 넣는다
   - 뻔한 결론 대신 여운 있는 마지막 문장
3. **자기 점검** — 다시 쓴 글을 위 8개 지문 기준으로 재검사. 남아 있으면 한 번 더.
4. **변경 노트** — 무엇을 왜 바꿨는지 2~3줄로 요약.

## 출력 형식 (Output)
```
[다시 쓴 글]
...

[무엇을 바꿨나]
- 예: 헤징 5곳 제거, 문장 길이 다양화, 리스트 → 산문, 결론부 교체
```

## 예시 (Example)
- 입력: "저는 데이터 분석에 열정을 가지고 있으며, 다양한 프로젝트를 통해 많은 것을 배웠습니다. 또한 팀워크를 중요하게 생각합니다."
- 출력: "숫자가 거짓말을 할 때를 잡아내는 게 제 일의 핵심입니다. 지난 프로젝트에서 모델이 너무 잘 나와 의심했더니, 예측 시점엔 없을 데이터가 새고 있었죠. 팀워크요? 제 분석을 팀이 먼저 반박하게 두는 것 — 그게 신뢰의 시작이라 믿습니다."

## 주의 (Guardrails)
- **사실·숫자·인용을 절대 바꾸지 않는다.** 문체만 손댄다.
- **정직한 용도로만.** 내 진짜 글을 자연스럽게 만드는 것이 목적이다. 학술 부정행위, 표절 은폐, AI 탐지 회피를 통한 기만 목적으로는 쓰지 않는다.
- 원저자의 톤과 개성을 존중한다 — 내 목소리를 지우지 않는다.
