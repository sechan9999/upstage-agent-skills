# Skill: Bilingual Explainer (쉬운 설명 · 영어/한국어)

> 어려운 개념을 **비유 하나 + 쉬운 말**로, **영어와 한국어 둘 다** 설명합니다.
> 비전문가도 이해하게, 그러나 정확성은 훼손하지 않습니다.

**환경:** 타임리 Agent × Solar Pro 4

---

## 언제 쓰나 (Trigger)
- "쉽게 설명해줘", "비유로", "초등학생도 알게", "영어로도 설명"
- 기술/전문 개념을 비전문 청중(면접관·경영진·고객)에게 전달할 때
- 발표·문서·포스트용 설명 초안이 필요할 때

## 입력 (Input)
- 설명할 개념/용어
- (선택) 청중(경영진/고객/일반), 톤, 길이

## 동작 (Instructions)
1. **핵심 파악** — 이 개념이 실제로 무엇이고, 왜 중요한지 한 문장으로.
2. **비유 하나** — 일상에서 가져온 정확한 비유. (너무 많으면 오히려 혼란 → 하나만 강력하게)
3. **쉬운 설명** — 전문 용어 없이 3~5문장. 필요한 전문 용어는 즉시 풀어씀.
4. **양 언어** — 영어 버전과 한국어 버전을 각각. 번역투가 아니라 각 언어로 자연스럽게.
5. **정확성 점검** — 쉽게 만들다가 틀리지 않았는지 확인. 중요한 단서(caveat)는 한 줄 남김.

## 출력 형식 (Output)
```
[EN]
Analogy: ...
In plain terms: ...

[KO]
비유: ...
쉽게 말하면: ...

(주의/한계 — 있으면 한 줄)
```

## 예시 (Example)
- 입력: "RAG를 쉽게 설명해줘 (영/한)"
- 출력:
  - **EN** — "Imagine an assistant locked in a room since last year — before answering, it first fetches the exact pages that matter and answers only from those, citing each. That's retrieval-augmented generation."
  - **KO** — "작년부터 방에 갇혀 회사 문서를 모르는 비서가, 답하기 전에 관련 페이지를 먼저 찾아와 그것만 근거로 답하고 출처를 다는 것 — 그게 RAG입니다."
  - (주의: 검색이 틀리면 답도 틀린다 → 검색 품질이 핵심)

## 주의 (Guardrails)
- **정확성 > 단순함.** 쉽게 만들려고 사실을 왜곡하지 않는다.
- 비유는 정확한 것만. 어긋나는 비유는 오해를 낳으므로 쓰지 않는다.
- 양 언어 모두 **그 언어로 자연스럽게** (직역투 금지).
