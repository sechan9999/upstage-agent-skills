# Excel Analyzer

## 스킬의 범위와 한계 (먼저 읽을 것)

- 이 스킬은 `scripts/analyze_excel.py`(Pandas/openpyxl 기반)가 계산한 **결정론적 사실**과,
  그 사실을 바탕으로 어시스턴트가 작성하는 **해석/개선 방안**을 분리한다. 숫자·진단 결과는 항상
  스크립트에서 나와야 하고, "이 부서는 문제가 있다" 같은 판단은 스크립트 출력에 실제로 근거가
  있을 때만 쓴다 — 데이터에 없는 원인을 추측해서 적지 않는다.
- **헤더/데이터 영역 감지는 휴리스틱이다.** 처음 15개 행을 스캔해 "이 행 아래에 숫자형 데이터가
  있고, 이 행 자체는 비어있지 않은 고유한 문자열들로 이뤄져 있다"는 점수가 가장 높은 행을
  헤더로 판단한다.
  - 테이블 중간의 단일 빈 행(Blank Row)으로 인해 데이터가 조기 절단되지 않도록 보호된다.
  - 테이블 최하단에 붙은 '합계/총계/소계' 행은 데이터 오염(평균/최댓값 왜곡)을 막기 위해 데이터 영역에서
    자동 분리되어 교차 검증으로 연결된다.
- **형식 오류 판정은 50% 임계치 휴리스틱이다.** 한 컬럼의 결측 아닌 값 중 절반 이상이 숫자로
  파싱되면 그 컬럼을 "숫자형"으로 보고, 나머지 파싱 안 되는 값들을 형식 오류로 표시한다.
- **사번, 연도, 코드 등 비통계성 숫자 컬럼은 4분위 분석 대상에서 자동 제외된다.**
  사번이나 연도처럼 숫자로 적혀 있지만 실제로는 식별자이거나 연도인 컬럼은 제외하고,
  실제 금액, 수량, 실적 등 변동성이 있는 핵심 지표 컬럼을 우선 선정하여 분석한다.
- **4분위(Q1~Q4) 구간 분석은 전 구간(4개 버킷)을 제공한다.**
  - Q1 (하위 25%): 최솟값 ~ Q1
  - Q2 (중하위 25%): Q1 ~ 중앙값(Median)
  - Q3 (중상위 25%): 중앙값 ~ Q3
  - Q4 (상위 25%): Q3 ~ 최댓값
  각 구간별 경계값, 레코드 수, 비중(%), 그리고 성명/품목명 등 가장 직관적인 대표 식별자 샘플을
  함께 제시한다.
- **요약표-원본 교차검증은 상단 프리앰블과 하단 합계행 모두를 지원한다.**
  합계/총계 레이블과 숫자가 헤더 위쪽(preamble)에 있거나 테이블 최하단(footer)에 있으면,
  실제 데이터의 합계와 일치하는지(OK/MISMATCH 및 delta)를 자동으로 대조한다.

## 왜 이 스킬이 필요한가

엑셀 파일을 받으면 시트가 몇 개인지, 첫 줄이 제목인지 헤더인지, 하단에 합계행이 데이터에 섞여
있어 평균을 왜곡하는지 확인하는 데 시간이 많이 소모된다. 이 파악 단계를 건너뛰고 바로
"평균이 얼마다" 식으로 답하면, 합계 행까지 데이터로 계산해 총합이 2배로 부풀거나
형식이 깨진 값을 빼먹고 계산하는 치명적인 실수가 발생한다.

이 스킬은 그 파악·계산 단계를 결정론적 스크립트로 먼저 끝내고, 어시스턴트는 그 결과를
"경영요약 · 품질진단 · 4분위 핵심지표 분석" 형태로 체계화하여 전달한다.

## 단계별 사용법

1. **파일 확인**: 엑셀(.xlsx/.xls) 또는 CSV 파일 경로를 확보한다. 시트가 많으면 전체를 볼지
   특정 시트만 볼지 사용자에게 확인한다(생략하면 전체 시트).
2. **스크립트 실행**:
   ```bash
   python scripts/analyze_excel.py FILE.xlsx [--sheet 시트명] [--json]
   ```
   `pandas`, `openpyxl`이 없으면 먼저 `pip install pandas openpyxl`을 안내한다.
3. **리포트 검토 (시트별)**:
   - 헤더 행 / 데이터 행 수 / 하단 합계행 분리 여부 확인
   - 컬럼별 결측치 및 형식 오류(문자/숫자 혼합)
   - 요약통계 (건수/평균/표준편차/사분위/최댓값·최솟값)
   - 4분위(Q1~Q4) 구간 분포 (경계값, 건수, 비중, 대표 식별자 샘플)
   - 그룹 비교 (부서/기간/항목별 sum/mean/count)
   - 이상치 탐지 (IQR 기준 극단치)
   - 요약표-원본 교차검증 결과 (상단/하단 합계 OK 또는 MISMATCH delta)
4. **출력 작성**: 채팅창에서 바로 읽을 수 있는 텍스트 요약과 함께, 필요 시 표나 스프레드시트 형태로 제시한다.

## 출력 형식

1. **경영요약 (Executive Summary)**: 파일 종류 추정(급여/실적/예산/재고/설문 등), 시트/데이터 규모,
   가장 중요한 통찰 2~3개 (예: 하단 합계 정합성 일치, 상위 25% 그룹의 쏠림 현상 등) — 3~5줄 요약.
2. **데이터 품질 진단 (Data Quality)**:
   - 결측치 / 중복 행 / 형식 오류(숫자 컬럼에 섞인 텍스트) 요약 표.
   - 합계 교차검증 결과 (상단/하단 합계와 실제 데이터 합계의 일치 여부 명시).
3. **핵심 4분위(Q1~Q4) 지표 분석 (Key Metrics & Quartiles)**:
   - 핵심 지표별 4분위 구간 분포 표 (Q1~Q4 구간명, 경계값 범위, 인원/건수, 비중, 대표 샘플).
   - 그룹별(부서/항목/기간) 비교 및 특이사항.
4. **개선 방안 및 액션 아이템**: 진단 결과(결측/형식오류/MISMATCH/하위 구간)에 근거한 실행 방안 제시.
   데이터에 없는 원인은 추측하지 않고 "원인 확인 필요 지점"으로 표시.
