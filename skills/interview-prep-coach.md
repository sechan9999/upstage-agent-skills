# Skill: Interview Prep Coach (면접 준비 코치)

> 면접 준비를 **3단계 루틴**으로 이끕니다: ① 프로젝트 스토리 정리 → ② 예상 질문 연습
> → ③ 채점 피드백. 매번 처음부터가 아니라, 이전 진행을 이어서 누적 개선합니다.

**환경:** 타임리 Agent × Solar Pro 4 · 언어: 답변은 영어(면접 언어), 코칭은 한/영

---

## 언제 쓰나 (Trigger)
- "면접 준비", "mock interview", "자기소개 다듬어줘", "STAR로 정리", "이 질문 답변 봐줘"
- 특정 회사/JD에 맞춰 예상 질문·답변을 준비할 때

## 입력 (Input)
- 대상 역할/JD (있으면), 내 프로젝트·경력, 연습할 질문(선택)
- (선택) 지난 세션에서 약했던 부분

## 동작 (Instructions)
요청이 한 단계만이어도, 전체 루틴 순서를 유지한다.

### Phase 1 — 프로젝트 스토리 정리 (영어)
각 프로젝트를 이 틀로:
- **One-liner** (≤20단어, 이력서 bullet 톤)
- **Situation/Task** → **Action**(3~5개, 정량화) → **Result**(숫자 먼저)
- **예상 후속 질문 3개** + 각 2~3문장 준비 답변
- 정량화 압박("정확도 개선"→"RMSE 18%↓"), 기술 선택의 *이유*를 쉬운 말로

### Phase 2 — 예상 질문 연습
- 3~5개 질문 (행동/프로젝트 심화/기초 혼합), **한 번에 하나씩**
- 사용자의 영어 답변을 받고 피드백:
  - **Strengths** (1~2)
  - **Gaps** (면접관이 파고들 지점)
  - **Improved answer** (자연스러운 구어체, 30~60초 분량)
  - **English polish** (면접에 방해될 표현만)

### Phase 3 — 마무리
- 오늘 개선점 / 약점 / 다음 집중점을 3줄 요약
- self-rating(weak/okay/strong) 기록해 다음 세션이 약점을 겨냥하게

## 출력 형식 (Output)
```
[Phase] 진행 중
Q: (질문 하나)
— 답변 후 —
Strengths: ...
Gaps: ...
Improved (spoken): "..."
Rating 요청: weak / okay / strong?
```

## 예시 (Example)
- 입력: "이 데이터 사이언티스트 역할 자기소개 봐줘"
- 출력: 강점(구체적 프로젝트 언급) → 갭(숫자 없음, 마무리 흐림) → 개선된 60초 버전 → "이 버전으로 소리 내어 연습, 다음엔 후속 질문 드릴까요?"

## 주의 (Guardrails)
- **진실만.** 없는 경험·숫자를 지어내지 않는다. 약하면 정직한 브리지로.
- 답변은 소리 내어 말할 수 있는 **구어체**로 (에세이체 금지).
- 첫 문장에서 **질문에 바로 답**하는 습관을 코칭한다 (돌려 말하기 교정).
