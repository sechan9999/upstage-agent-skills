# Skill: Token Cost Optimizer (토큰 비용 라우터 · 낭비 제거)

> AI 코딩/에이전트 작업의 **토큰 낭비를 진단하고, 작업을 맞는 모델로 라우팅**해
> 같은 결과를 훨씬 싸게 냅니다. 시니어 AI 엔지니어들의 10가지 노하우를 하나의 스킬로.

**환경:** 타임리 Agent × Solar Pro 4 · 언어: 한국어/영어

> *"AI 코딩 비용의 90%는 불필요한 비용이다."* — Andrej Karpathy (인용 출처: X @DeRonin_)
> 12개월 뒤, 월 \$200 쓰는 개발자와 \$4,000 쓰는 개발자의 격차는 **실력이 아니라 라우팅**이다.

---

## 언제 쓰나 (Trigger)
- AI 코딩/에이전트 비용이 예상보다 많이 나올 때
- "이 작업 왜 이렇게 토큰을 많이 쓰지?", "비용 줄여줘", "이거 더 싸게 할 수 있어?"
- 워크플로우/프롬프트/툴콜 루프를 비용 관점에서 점검할 때

## 입력 (Input)
- 점검할 작업/워크플로우 설명 (또는 프롬프트·툴콜 로그·비용 내역)
- (선택) 현재 사용 모델·구독·턴당 비용

## 동작 (Instructions)
아래 **10가지 낭비 패턴**을 순서대로 점검하고, 각 항목에 대해 [발견 여부 · 예상 낭비 · 수정안]을 낸다.

### A. 컨텍스트 낭비 (입력 토큰)
1. **과잉 자동 로딩** — 30줄 고치는데 파일 50개가 자동 로딩? → 턴당 비용 폭증, 입력의 ~80% 낭비. **수정:** 관련 파일만 명시적으로 로드.
2. **"혹시 몰라서" 파일 포함** — 3,000토큰이면 될 걸 80,000토큰으로. **수정:** 필요한 것만. 불확실하면 먼저 검색/목록 후 선택 로드.
3. **재시도마다 전체 리포 재전송하는 툴콜 루프** — 이것만 고쳐도 **30~50% 절감**. **수정:** diff/증분만 전송, 이전 컨텍스트 재사용.

### B. 프롬프트 캐싱 (재사용)
4. **매 호출마다 프롬프트 앞부분(prefix) 변경** — 앞부분이 바뀌면 캐시 무효화 → 전체 재읽기 → 비용 폭증. **수정:** 안정적 prefix 유지(시스템/지침을 앞에 고정, 가변 부분은 뒤로).
5. **세션마다 환경 재학습** — 매번 컨텍스트를 다시 가르침. **수정:** **SKILL 파일 한 번** 작성 → \$4가 \$0.30으로.

### C. 모델 라우팅 (작업↔모델 매칭)
6. **최상위 모델 무지성 고정 (단일 셋업)** — 모든 작업에 프리미엄 = 지금 가장 비싼 실수. **수정:** 멀티 모델 셋업.
7. **린트·포맷·리네임에 최상위 모델** — \$0.02짜리를 \$0.60에, **30배** 지불. **수정:** 기계적 작업은 저가 모델/툴로.
8. **기본 모델을 최상위로** — 작업 대부분은 **1/6 가격 모델**로 동일 품질. **수정:** 기본을 중저가로, 어려운 것만 승급(escalate).

### D. 배치 & 구독
9. **작은 질문 10개를 하나씩** — 배치 한 번으로 **70~90% 절감**. **수정:** 관련 질문을 묶어 한 번에.
10. **중복 구독 3개** — 진짜 쓰는 건 하나, 나머지 둘은 습관. **수정:** 실사용 하나만 남기고 정리.

## 출력 형식 (Output)
```
💸 토큰 낭비 진단
발견된 패턴 (심각도순):
  • [패턴 #] [무엇] — 예상 낭비: [%/금액] — 수정: [구체적 조치]
  ...
빠른 승리 (지금 바로):
  1. (가장 큰 절감 하나)
예상 총 절감: ~XX%
라우팅 규칙 제안:
  기계적 작업(린트/포맷/리네임/단순 추출) → 저가 모델
  일반 코딩/분석 → 중가 모델(기본)
  복잡한 설계/디버깅 → 최상위 (escalate only)
```

## 예시 (Example)
- 입력: "30줄 버그 픽스인데 리포 전체가 로딩되고, 최상위 모델 고정, 재시도마다 전체 재전송, 턴당 $1.20"
- 출력:
  - 💸 #1 과잉 로딩 (입력 80% 낭비) → 관련 3파일만 로드
  - 💸 #3 재시도 전체 재전송 → diff만 (30~50%↓)
  - 💸 #7/#8 버그픽스에 최상위 모델 → 중가 모델로 (동급 품질, 1/6가)
  - ▶ 빠른 승리: 자동 로딩 범위부터 제한 → 턴당 $1.20 → ~$0.25 예상
  - 예상 총 절감: ~75%

## 주의 (Guardrails)
- **품질이 실제로 유지되는 작업에만** 저가 모델 라우팅. 복잡한 추론/설계는 무리하게 낮추지 않는다 — 싸게 하려다 틀리면 재작업이 더 비싸다.
- 절감 추정치는 **범위(range)**로 제시하고, 근거(어느 패턴에서 얼마)를 함께 밝힌다.
- 비용만 최적화하고 결과 품질을 검증 안 하면 안 된다 — 라우팅 후 산출물의 정확성은 여전히 확인.
